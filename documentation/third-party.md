## React Native core and its C++ dependencies

Each library is a pinned shallow Git submodule under `modules/react_native_bindings/thirdparty/`
and is compiled unmodified from `react_native_sources.py` in a cloned SCons environment
with warnings disabled. Godot-specific behavior comes from `react_platform/`, which shadows
upstream `platform/cxx` headers and replaces three listed sources.

The versions match React Native 0.87.1's own pins (`gradle/libs.versions.toml`).
`scripts/bootstrap.sh` downloads Boost, verifies its checksum and extracts only the headers
into the ignored `thirdparty/boost/`. At build time `react_native_sources.py` writes glog's
configured headers and double-conversion's include layout into the ignored
`thirdparty/configured/`, as React Native's Android build does. Hermes is built against
React Native's JSI (`-DJSI_DIR`), with the debugger enabled.

`modules/react_native_bindings/generated/` holds React Native codegen output for the
`FBReactNativeSpec` and `react-native-godot` specs. It is committed and regenerated by
`packages/react-native-godot/scripts/codegen.cjs`.

Godot, React Native, React, Metro, Node.js, and the compiler toolchain are pinned build or
runtime inputs rather than vendored module source. Their versions are recorded in
`baseline.env` and `documentation/supported-versions.md`.

## Godot and sample font

Godot is pinned to `ed1daf0bf001b61586d9930840f2f1394092c079` and built without local
changes under its MIT license.

`samples/game-ui/assets/OpenSans.woff2` copies the pinned Godot
`thirdparty/fonts/OpenSans_SemiBold.woff2` unchanged. Its SIL Open Font License 1.1 is
included as `assets/LICENSE.OpenSans.txt`. This is a deterministic sample font;
applications inherit their Godot theme by default.

`samples/game-ui/assets/NotoSansArabic.ttf` and `NotoSansHebrew.ttf` copy the variable
`NotoSansArabic[wdth,wght].ttf` and `NotoSansHebrew[wdth,wght].ttf` from
`https://github.com/google/fonts` at `8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5`, unchanged.
Their SIL Open Font License 1.1 files are included as `assets/LICENSE.NotoSansArabic.txt`
and `assets/LICENSE.NotoSansHebrew.txt`. Right-to-left and bidi tests use them because CI
has no system fonts for those scripts.

## AccessKit

The Godot build links the AccessKit C SDK `0.22.3` that the pinned engine selects in
`godot/misc/scripts/install_accesskit.py`. `scripts/bootstrap.sh` runs that script, which
downloads Godot's static build from `https://github.com/godotengine/godot-accesskit-c-static`
into the ignored `godot/bin/build_deps/accesskit/`. AccessKit is MIT or Apache-2.0
licensed and is linked unmodified.

React Native files are not vendored or modified in references. The `react-native-godot`
package contains whole-file derived copies of Alert, TextInput, TextInputState and Modal, each
guarded by the SHA-256 of its 0.87.1 base file in `overrides.json`. They remain under
the upstream React Native MIT license.

## Local network fixture

`requirements-ci.txt` pins test-only `websockets==15.0.1` (BSD-3-Clause, upstream
https://github.com/python-websockets/websockets). It runs only in the Python localhost
fixture and is not linked or shipped in the Godot runtime. HTTP/TLS fixtures use Python
stdlib servers; the checked-in test certificate/key identifies only localhost, is
non-production test material, and is trusted explicitly in the test project. Native
HTTP/TLS/WebSocket use Godot's existing facilities and licenses.
